# Security

This library reads window insets and computes offsets. It performs no I/O, holds no credentials,
opens no connections and requires no permissions, so the realistic severity of anything found here
is low.

Report a suspected vulnerability privately through GitHub's
[security advisories](https://github.com/damson/compose-hardware-insets/security/advisories/new)
rather than in a public issue. Expect an acknowledgement within a week.

## Supported versions

Only the latest 0.x release receives fixes while the project is pre-1.0.
